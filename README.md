This repository contains data for the computational experiments in the article "Drone-Enabled Early Diagnosis of Human Immunodeficiency Virus in Infants" by Alborz Hassanzadeh and Laurent Alfandari.

Column definitions and file-format conventions are provided in DATA_DICTIONARY.md and transportation times are provided in T_Times.dat.

Experiment Set 1 contains data for the main analysis in Table 2, comparing the BaseCase, min-TAT, and min-CVaR networks across drone budgets.

Experiment Set 2 contains data for the cost-effectiveness analysis in Appendix Table 2, comparing 20 drones with one additional PCR machine per laboratory.

Experiment Set 3 contains data for the sensitivity analysis in Appendix Table 3, varying drone capacity, speed, and range.

Experiment Set 4 contains data for the sensitivity and cost-effectiveness analyses in Appendix Tables 4 and 5 under different drone specifications.

Experiment Set 5 contains the instances used to validate the MILP approximation in Appendix Tables 6 and 7.

Experiment Set 6 contains data for the min-CVaR sensitivity and robustness analysis with respect to parameter beta in Appendix Tables 8 and 9.
